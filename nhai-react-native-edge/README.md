# NHAI Datalake 3.0 Edge Application Integration

This standalone React Native module fulfills the requirements of **Hackathon 7.0** for building an offline-capable, cross-platform (Android + iOS) attendance application with localized Machine Learning constraints (<20MB).

## Core Features Implemented

1. **Active Liveness Detection (0MB footprint):** Uses Google ML Kit's Face Detection to detect blinks and smiles at 60fps native speeds within a React Native Worklet frame processor.
2. **Offline Face Recognition (~4MB footprint):** Uses a quantized MobileFaceNet TFLite model via `react-native-fast-tflite` to extract embeddings offline and perform Cosine Similarity matching against registered worker profiles. Total ML footprint is well under the 20MB limit.
3. **Cryptographic Anti-Spoofing:** Every offline attendance record is ECDSA signed locally using a device private key. The backend verifies the signature before accepting the sync payload, ensuring records were generated by authorized tablets and not forged via API requests.
4. **Offline Sync & Purge Mechanism:** Records are cached locally using `react-native-quick-sqlite`. When connectivity is restored, the `OfflineSyncManager` pushes batches to the backend via JWT-authenticated requests and purges the local SQLite database upon HTTP 200 OK.
5. **Premium Glassmorphism UI:** Features a dynamic, animated camera overlay (`CameraOverlay.tsx`) with real-time user prompts and success transitions.

## Integration Steps for Datalake 3.0

Drop the `src` folder into your existing Datalake 3.0 React Native project and ensure you have the following packages installed:

```bash
npm install react-native-vision-camera react-native-worklets-core
npm install @react-native-ml-kit/face-detection
npm install react-native-fast-tflite
npm install @react-native-community/netinfo
npm install react-native-quick-sqlite
npm install elliptic uuid
```

### iOS Setup
Run `npx pod-install` or `cd ios && pod install`. You will need to add the Camera permissions to your `Info.plist`:
```xml
<key>NSCameraUsageDescription</key>
<string>NHAI needs camera access for biometric attendance.</string>
```

### Android Setup
Add the camera permission to `AndroidManifest.xml`:
```xml
<uses-permission android:name="android.permission.CAMERA" />
```

### Adding the Model
Place your `mobilefacenet.tflite` file in your Android `app/src/main/assets/` folder and link it correctly in XCode for iOS so the `TFLiteRecognition.ts` service can bundle it.

### Usage in App Navigation
Simply mount `<AttendanceScreen />` anywhere in your React Navigation stack!

```tsx
import { AttendanceScreen } from './src/screens/AttendanceScreen';

export default function App() {
  return <AttendanceScreen />;
}
```
